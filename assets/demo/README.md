# Demo asset sources

The Kestrel R17 weapon geometry is created by this project through
`game/shooter/demo/Scripts/prepare_first_person.py` and `UDemoEditorLibrary`.
The WAV files here are deterministic synthesized project audio, generated by
the same script. They do not contain recordings or samples from Apex Legends,
Titanfall, or Epic sample projects.

The arms mesh under `Content/demo/Character/Mannequin` derives from Epic's
bundled `MoverTests/Characters/Mannequins/Meshes/SKM_Manny_Simple`. The skeleton
and skinning are retained; body/head/leg geometry is removed. This remains Epic
Unreal Engine content, subject to its original terms. No First Person Sample
project was imported or used. Runtime dependencies on Mover content are removed.
