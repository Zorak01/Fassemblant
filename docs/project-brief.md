# Project brief

Status: discovery. Nothing below implies an engine or genre decision.

## Questions to answer together

- What does the player do repeatedly, and why is it fun?
- What is the smallest prototype that can test that idea?
- Who is the intended player, and what is the initial platform?
- Is the first prototype single-player or multiplayer?
- Which engine fits the team's skills and prototype needs?
- How much time can each person realistically contribute?

## Prototype scope

Choose one core mechanic, one small test environment, and one clear player goal. Start with placeholder visuals and audio. Add features only when they help test the core mechanic.

## Definition of done

A teammate can open the project using documented steps, play the core loop, and report what worked or failed. Known problems and next steps are written down.

## Team

Add each person's preferred name, interests, and availability after they agree to share them. Assign ownership per task rather than assuming permanent roles.
