# Decision log

Record agreed choices here so people can understand why the project works the way it does.

## Template

### YYYY-MM-DD — Decision title

- **Status:** proposed / accepted / superseded
- **Context:** What problem are we solving?
- **Decision:** What did we choose?
- **Reason:** Why this option?
- **Tradeoffs:** What limitations are we accepting?
- **Related issue or PR:** Link

## Open decisions

- Game concept and core mechanic
- Engine and version
- Target platform
- Single-player or multiplayer prototype
- Code and asset licensing
- Large asset storage
