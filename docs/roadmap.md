# Initial roadmap

## 1. Agree on the idea

- Collect a few short game pitches.
- Choose one core mechanic and a deliberately small prototype scope.
- Decide the initial platform and multiplayer requirements.
- Record the outcome in `decisions.md`.

## 2. Establish the project

- Select the engine and pin its version.
- Commit the smallest working engine project under `game/`.
- Add engine-specific ignore rules and exact run instructions.
- Decide how to store large source assets.

## 3. Build the first playable

- Implement the core interaction with placeholder assets.
- Add a clear goal, basic feedback, and a restart path.
- Check that another teammate can run it from a fresh clone.

## 4. Playtest and decide

- Have teammates play without coaching.
- Record confusing moments, bugs, and whether the core mechanic is enjoyable.
- Choose what to keep, change, or remove before expanding scope.

No dates are committed yet. Turn agreed tasks into GitHub issues with concrete acceptance criteria.
